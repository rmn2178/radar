# Content guide

## Principles

- Publish only verified information. Do not invent names, dates, portraits, achievements, technical results or clinical validation.
- Leave unknown fields blank. Undated events display “Date not recorded” rather than an invented date.
- Preserve distinctions such as “paper accepted” vs “paper uploaded”.
- Use simply “RADAR Centre” in public branding until the official expansion is confirmed (the emblem and report wording differ).
- Do not attribute generated quotations to named faculty without permission; attribute institutional statements to “RADAR Centre”.

## Writing style

- Calm, credible, human-centred institutional voice. Short headings; supporting paragraphs of 1–3 sentences.
- Avoid startup/SaaS language, hype and unsupported superlatives.
- Use sentence case for body text; eyebrows may be uppercase.

## Images

| Use | Recommended | Format |
| --- | --- | --- |
| Member portrait | 800×1000 (4:5), authorised photo only | WebP/JPEG |
| Event/project cover | 1600×900 (16:9) | WebP/JPEG |
| Gallery | 1600px longest edge | WebP/JPEG |
| Logos | Original source files, unchanged | PNG/JPEG |

- Upload real institutional photographs only. Where none exists, the site renders an elegant labelled placeholder — never a fake laboratory, doctor or building.
- Always add descriptive alt text; captions are optional.
- Large photos may be compressed in the browser before upload; logo artwork is preserved.

## Records

- **Member:** name, designation, department, category, biography, research interests, optional email/LinkedIn/Scholar/website. Use a placeholder portrait until an authorised photo is supplied.
- **Event:** title, category, nullable start/end dates, venue, short/full description, outcomes, participants, gallery, related project slugs, optional registration/report URL.
- **Project:** title, category, short description, problem/motivation/approach/solution, technologies, mentor, contributors, year, status, gallery, optional GitHub/demo/publication. Keep “Details pending” until confirmed.
- **Achievement:** title, person, type, description, verified date, supporting media/URL.

## SEO

- Set a concise SEO title and description per page; the homepage defaults to “RADAR Centre | Rajalakshmi Institute of Technology”.
- Use descriptive slugs and meaningful image alt text.
- Structured data uses only verified institution/contact fields.
